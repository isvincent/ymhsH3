# ymhsH3

## 一年一格：楊梅高中空拍時光機 1968–2026

約 5 分鐘的校史動態圖文網頁，從 1968 年改制為省立楊梅高中開始，每一年畫一格空拍畫面，一格一格翻到 2026 年。

- 單一 HTML 檔（`index.html`），畫面全部是內嵌 SVG，以 1920×1080 畫幅播放
- 背景音樂與音效（翻頁、快門、轉場、腳步、工地聲）都由 Web Audio 即時合成
- 旁白使用瀏覽器預設語音（Web Speech API），語速 1.2 倍
- 可以播放、暫停、拖曳、跳章節，也可以點下方底片格或「跳到某一年」按鈕直接看那一年

線上觀看：在 repo 設定開啟 GitHub Pages（Branch：`main`，資料夾：`/ (root)`）之後，網址是 https://isvincent.github.io/ymhsH3/

**注意**：片中的地圖是依校史繪製的**示意圖**，不是實際的空拍或衛星影像。網頁下方附有 Google Earth、Google 地圖、國土測繪圖資服務雲、中研院百年歷史地圖等真實影像的查詢連結。
